# 屋台にのきち レジ

屋台「にのきち」で使う、受け取り待ちの管理つきレジアプリ。

**このアプリの中心は会計ではなく、お会計の済んだお客さんと焼き上がった商品を結びつけること。**

- 設計メモ → [docs/design.md](docs/design.md)
- 素の HTML と JavaScript だけで作ってあります。npm もビルドも使いません

## ファイル

| ファイル | 中身 | 直すか |
|---|---|---|
| `index.html` | アプリぜんぶ（画面・動き・保存） | **ここだけ直す** |
| `sw.js` | 電波がなくても開けるようにするもの | 直さない（※下記） |
| `manifest.json` | ホーム画面のアイコンの設定 | 直さない |
| `icon-192.png` / `icon-512.png` | アイコン | 直さない |

※ `index.html` を直したら、`sw.js` のいちばん上にある `VERSION` の数字を1つ増やしてください。
古い中身が残り続けるのを防げます。

## はじめて使うまで

1. この内容を GitHub Pages に置く（リポジトリの Settings → Pages → `main` ブランチ）
2. **スマホの Safari** で出てきたアドレスを開く
3. 共有ボタン → **「ホーム画面に追加」**
4. 以後は**かならずホーム画面のアイコンから開く**
5. 設定 →「いますぐ試す」を1回押して、**ちゃんと元に戻ることを自分の目で確かめる**

## 使いかた

```
注文を聞く → 商品を押す → 色を1つ押す → 預かりを押す → 確定
                                   ↓
                      受け取り待ちの一覧に並ぶ
                                   ↓
     「ステーキ2つでお待ちの方！」と注文内容で呼ぶ
                                   ↓
        渡す直前に「ステーキ2つですね」と確かめる
                                   ↓
                     「受け取り済み」を押す
```

最短3タップ（商品・色・確定）。おつりを計算しても4タップ。

- **お客さんを呼ぶのは注文の内容。** お客さんは自分の注文を覚えているので、手を挙げてくれます
- **色はこちらが見るための印。** お客さんに覚えてもらう必要はありません
- 同じ内容・同じ色の人が並んだときだけ、服のとくちょうを足す画面が出ます
- 名前で見分けたいときは「名前を打つ」から入れられます

## 守ってほしいこと3つ

1. **ホーム画面のアイコンから開く。** ブラウザのタブからは開かない
2. **シークレットモード（プライベートブラウズ）では絶対に使わない。** 閉じるとぜんぶ消えます
3. **営業のあとは必ず「記録を書き出す」。** 混む前に1回やっておくともっと安心です

あとはモバイルバッテリーを持って、つなぎながら使ってください。

## 注文が消えない仕組み

記録は**1行ずつ追記していく**作りです。前の行は絶対に書き換えません。
だから書き込みが失敗しても、**最悪いま押した1件だけ**で止まります。

| 壊れ方 | どうなるか |
|---|---|
| アプリが落ちた／電源が切れた／間違って閉じた | **開き直すと、何もしなくても続きから始まります** |
| 他のアプリから戻ったら読み込み直された | **同じく、そのまま戻ります** |
| 長く使わずブラウザがデータを消した | 書き出したファイルから戻せます |
| スマホ自体が壊れた | アプリでは守れません（モバイルバッテリーで備える） |

画面の右上にいつも `保存OK 19:42:03` と出ています。赤くなったら、注文を受けるのをやめて書き出してください。

## 直すとき

`index.html` を開いて直すだけです。スマホからでも直せます。

- 画面の見た目 … `<style>` の中
- 動き … `<script>` の中（はじめに「保存」、次に「画面」、最後に「操作」の順）
